Mathematical Reference & Syntax

Differential Equations

Define state derivatives using prime or Leibniz notation:

x' = -y - z or dx/dt = -y - z

Integration Solvers

• RK4: Classical fixed-step 4th-order Runge-Kutta.
• RK45 Dormand-Prince: Adaptive-step algorithm matching MATLAB's ode45.
• Symplectic Verlet: Geometric integrator preserving total energy in Hamiltonian systems.

Stability & Equilibria

Click the Equilibria button in the top bar to run multi-start Newton-Raphson root finding. It computes the Jacobian matrix and eigenvalues, classifying fixed points as Sinks, Sources, Saddles, or Spirals.

Analysis Views

• Phase Portrait: 2D orbits with nullclines (x'=0, y'=0) and vector field.
• Poincaré Section: Pierce the 3D continuous flow with a plane (z = z0) to reveal fractal cross-sections.
• Power Spectrum (FFT): Fast Fourier Transform isolating discrete periodic peaks vs continuous chaotic noise floors.
